# Taiwan Brawl Minesweeper

獨立的踩地雷小遊戲 owner repository。

## 第一版規則

- 遊戲開始前選擇 9×9、16×16 或 25×25。
- 按下開始後，棋盤尺寸鎖定，遊戲中不能切換。
- 每個格子保持固定尺寸；大棋盤透過移動視窗探索。
- 手機棋盤視窗固定顯示 9×9 格；9×9、16×16、25×25 都使用相同可視基準。
- 點擊翻開格子。
- 長按後拖曳上下左右移動視角。
- 長按但沒有移動時插旗或取消旗子。

目前已提供純 Dart 核心模型與 Flutter 手機 UI。大棋盤保持固定格子尺寸，超出視窗時使用長按拖曳移動視角。
